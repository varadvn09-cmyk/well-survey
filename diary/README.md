## 🌟 वैशिष्ट्ये (Key Features)

| वैशिष्ट्य | मोबाईल फोन (Mobile) | संगणक / लॅपटॉप (PC / Laptop) |
|---|---|---|

## 🚀 GitHub वर कसे अपलोड करावे? (How to Upload to GitHub)

### पर्याय १: आधीपासून असलेल्या GitHub Pages रिपॉझिटरीमध्ये जोडणे (जसे GeoDraft_SLP, kop, ltr)

आपल्या खात्यावर आधीच इतर ऍप्सचे फोल्डर्स असतील, तर यामध्ये दैनंदिनी जोडणे अतिशय सोपे आहे:

1. आपल्या GitHub रिपॉझिटरीमध्ये जा (उदा. `https://github.com/<username>/<repo>`).
2. **"Add file"** बटनावर क्लिक करा आणि **"Upload files"** निवडा.
3. या `github_upload_folder` मधील **सर्व फाईल्स** (`index.html`, `manifest.json`, `.nojekyll`, `profile.json`):
   - जर स्वतंत्र सब-फोल्डरमध्ये हवे असेल, तर फाईल्स ड्रॅग करण्यापूर्वी वर फाईल पाथ `diary/index.html` असा टाईप करा किंवा थेट `diary` फोल्डर अपलोड करा.
4. खाली **"Commit changes"** बटण दाबा.
5. आता आपली नवीन लिंक लगेच सुरू होईल:  
   `https://<username>.github.io/<repo>/diary/`

---

### पर्याय २: नवीन स्वतंत्र रिपॉझिटरी तयार करून GitHub Pages सुरू करणे (फक्त २ मिनिटांत)

1. [https://github.com/new](https://github.com/new) वर जा.
2. **Repository name:** `gsda-diary` (किंवा आवडीचे नाव) टाका.
3. **"Public"** पर्याय निवडा.
4. **"Create repository"** बटण दाबा.
5. नवीन पानावर **"uploading an existing file"** या लिंकवर क्लिक करा.
6. या फोल्डरमधील सर्व फाईल्स (`index.html`, `manifest.json`, `.nojekyll`, `profile.json`) निवडून अपलोड करा.
7. **"Commit changes"** दाबा.
8. रिपॉझिटरीच्या वरच्या मेनूमध्ये **"Settings"** ➔ डाव्या बाजूला **"Pages"** वर क्लिक करा.
9. **Build and deployment** अंतर्गत:
   - **Branch:** `main` (किंवा `master`) निवडा
   - **Folder:** `/ (root)` निवडा
   - **"Save"** बटण दाबा.
10. १ मिनिटात आपली मोफत कायमस्वरूपी लाईव्ह लिंक तयार होते:  
    👉 **`https://<username>.github.io/gsda-diary/`**

## 📲 मोबाईलवर होमस्क्रीनवर ऍप म्हणून कसे जोडावे? (Add to Home Screen)
1. मोबाईलच्या Chrome ब्राऊझरमध्ये वरील लिंक उघडा.
2. उजव्या कोपऱ्यातील **तीन ठिपके (⋮)** वर क्लिक करा.
3. **"Add to Home screen" (होम स्क्रीनवर जोडा)** किंवा **"Install app"** वर क्लिक करा.
4. मोबाईलवर इतर ऍप्सप्रमाणे **"GSDA Diary"** चे आयकॉन येईल आणि इंटरनेट नसतानाही ऍप चालू राहील!
