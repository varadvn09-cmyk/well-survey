# 📘 GSDA दैनिक दैनंदिनी पोर्टल (Daily Diary Web App)
> **महाराष्ट्र शासन | भूजल सर्वेक्षण आणि विकास यंत्रणा (GSDA)**  
> **अधिकारी:** श्री. विनायक नवनाथ निंबाळकर (सहाय्यक भूवैज्ञानिक)

---

## 🌟 वैशिष्ट्ये (Key Features)
* **२-पान A4 प्रिंट व PDF (मार्ग १ - Route 1):** १ ते २८ दिवस पान १ वर आणि २९ ते ३१ दिवस + मासिक गोषवारा पान २ वर अखंड सुरू राहतील. वरच्या बाजूस १८-२० मिमी टॅगिंग मार्जिन.
* **वार्षिक गोषवारा (Yearly Abstract):** एप्रिल ते मार्च १२ महिन्यांचा संपूर्ण एकत्रित सारांश, प्रिंट व एक्सेल डाऊनलोडसह.
* **मुक्कामाचे दिवस (Night Halt Days):** शो/हाईड पर्यायासह. अनचेक केल्यास प्रिंट व एक्सेलमध्ये १००% लपवले जाते.
* **अधिकृत नाव दुरुस्ती:** "प्रयोगशाळा तपासणी" हे संक्षिप्त व अधिकृत नाव.
* **Excel (.xlsx) सुबक लेआउट:** थेट २-पानांत पेज ब्रेकसह डाऊनलोड होणारी स्प्रेडशीट.
* **मोबाईल + PC पूर्ण सुसंगत:** टच कार्ड्स व्ह्यू आणि विस्तृत स्प्रेडशीट तक्ता.
* **१००% ऑफलाइन क्षमता:** इंटरनेटशिवाय स्थानिक पातळीवर संपूर्ण कार्यक्षम (IndexedDB व LocalStorage).

## 🚀 GitHub वर कसे अपलोड करावे? (How to Upload to GitHub)

### पर्याय १: नवीन स्वतंत्र रिपॉझिटरी तयार करून थेट लाईव्ह करणे (फक्त २ मिनिटांत)
1. [https://github.com/new](https://github.com/new) वर जा.
2. Repository name: `gsda-diary` (किंवा आवडीचे नाव) टाका.
3. **Public** निवडून **Create repository** वर क्लिक करा.
4. **"uploading an existing file"** वर क्लिक करून या फोल्डरमधील सर्व फाइल्स व फोल्डर्स ड्रॅग-अँड-ड्रॉप करून अपलोड करा.
5. **Commit changes** दाबा.
6. रिपॉझिटरीच्या **Settings** ➔ **Pages** वर जा.
7. **Branch:** `main` (किंवा `master`) आणि **Folder:** `/ (root)` निवडून **Save** दाबा.
8. १ मिनिटात आपली मोफत कायमस्वरूपी लाईव्ह लिंक तयार होते:  
   👉 **`https://<username>.github.io/gsda-diary/`**

---

### पर्याय २: आधीपासून असलेल्या GitHub Pages रिपॉझिटरीमध्ये (जसे GeoDraft_SLP) जोडणे
1. आपल्या अस्तित्वात असलेल्या रिपॉझिटरीमध्ये जा.
2. **"Add file"** ➔ **"Upload files"** निवडा.
3. या पॅकेजमधील `diary` फोल्डर थेट अपलोड करा.
4. **Commit changes** दाबा.
5. आपली लिंक सुरू होईल:  
   👉 **`https://<username>.github.io/<repo>/diary/`**

---

## 💻 Windows Desktop App (संगणकावर थेट चालवणे)
जर संगणकावर इंटरनेटशिवाय किंवा कोणत्याही कमांडशिवाय चालवायचे असेल तर मुख्य फोल्डरमधील `GSDA_Daily_Diary.exe` वर डबल-क्लिक करा.
