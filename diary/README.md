# दैनिक दैनंदिनी ऍप (Official Daily Diary Application)
**भूजल सर्वेक्षण आणि विकास यंत्रणा, लातूर (GSDA LATUR)**  
**अधिकारी: श्री विनायक नवनाथ निंबाळकर (सहाय्यक भूवैज्ञानिक)**  
**Excel File:** `Diary_Nimbalkar_Latur.xlsx`

---

## 🌟 ऍपची मुख्य वैशिष्ट्ये (Key Features)

1. **संपूर्ण Excel डेटा एकत्रीकरण (Full 22-Month Excel Synchronization):**
   - ऑक्टोबर २०२४ पासून मे २०२६ पर्यंतच्या सर्व २२ महिन्यांचा संपूर्ण डेटा थेट `Diary_Nimbalkar_Latur.xlsx` मधून लोड होतो.
   - ऍपमध्ये केलेल्या सर्व नोंदी थेट Excel फाइलमध्ये सुरक्षितपणे सेव्ह होतात (स्वयंचलित बॅकअपसह).

2. **दैनंदिनी नोंदी व्यवस्थापन (Daily Diary Management):**
   - प्रत्येक दिवसाची दिनांक, वार, प्रस्थान (कोठून), प्रस्थान वेळ, आगमन (कोठे), आगमन वेळ, वाहन (शा.वा./खा.वा./बस), प्रवास अंतर (कि.मी.), भाडे (रु.), आणि कामाचा सविस्तर तपशील.
   - शासकीय कामांसाठी त्वरित सजेशन चिप्स (उदा. *कार्यालयात उपस्थित*, *अटल भूजल योजना बैठक*, *स्थानिक भूजल सर्वेक्षण*, *निरीक्षण विहिरींची वाचने*, *जिल्हाधिकारी बैठक*, *साप्ताहिक सुट्टी* इ.).
   - वर्गवारी चेकमार्क: एकूण (१), सुट्टी (१), रजा (१), दौरा (१), बैठक (१).

3. **मासिक कॅलेंडर दृश्य (Visual Monthly Calendar):**
   - महिन्यातील सर्व दिवसांचे रंगीत कॅलेंडर दृश्य (हिरवा: कार्यालय, निळा: दौरा, नारंगी: बैठक, लाल: सुट्टी, जांभळा: रजा).
   - कोणत्याही तारखेवर क्लिक करून लगेच नोंद पाहणे व संपादित करणे.

4. **मासिक गोषवारा व क्षेत्रीय प्रगती (Monthly Summary & Field Progress):**
   - **मासिक गोषवारा:** महिन्याचे एकूण दिवस, कार्यालयीन दिवस, दौरे/फिरतीचे दिवस, शासकीय सुट्टी, बैठकांचे दिवस, रजेचे दिवस, प्रशिक्षण दिवस आणि एकूण फिरती अंतर (कि.मी.) ची स्वयंचलित अचूक गणना.
   - **क्षेत्रीय प्रगती:** स्थानिक भूजल सर्वेक्षण, अटल भूजल योजना, निरीक्षण विहिरी, वाळू सर्वेक्षण, भूजल मूल्यांकन, प्रयोगशाळा, न.पा.पु. सर्वेक्षण, टंचाई आदी योजनांमधील गावे व प्रकरणांची नोंद.

5. **अधिकृत शासकीय प्रपत्र मुद्रण / PDF (Official Print & PDF Export):**
   - महाराष्ट्र शासनाच्या अधिकृत प्रपत्रानुसार A4 लँडस्केप मुद्रण फॉरमॅट.
   - अधिकारी स्वाक्षरी आणि मा. उपसंचालक, भूजल सर्वेक्षण आणि विकास यंत्रणा, लातूर यांची प्रतिस्वाक्षरी.

6. **वाहन चालक दैनंदिनी (Driver Travel Log - परिशिष्ठ १७):**
   - शासकीय वाहनाने (शा.वा.) केलेल्या सर्व दौऱ्यांची श्री शत्रुघ्न विश्वनाथ भोसले (वाहन चालक) यांच्यासाठी स्वतंत्र प्रवास दैनंदिनी.

7. **सर्वंकष शोध (Universal Search):**
   - ऑक्टोबर २०२४ ते मे २०२६ मधील कोणत्याही गावाची भेट, बैठक, योजना किंवा काम एका सेकंदात शोधा.

8. **नवीन महिना तयार करणे (New Month Generator):**
   - जून २०२६ किंवा पुढील कोणत्याही महिन्याचे पान एका क्लिकवर तयार करा. कॅलेंडर तारखा, रविवार व २/४ थ्या शनिवारच्या साप्ताहिक सुट्ट्या आणि शासकीय सुट्ट्या स्वयंचलित भरल्या जातात.

## 🚀 ऍप कसे सुरू करावे (How to Run)

### पद्धत १ (सर्वात सोपी - 1-Click Launch):
- फोल्डरमधील **`run_diary_app.bat`** या फाइलवर **डबल-क्लिक (Double Click)** करा.
- ऍप स्वयंचलितपणे सुरू होईल आणि तुमच्या ब्राऊझरमध्ये `http://127.0.0.1:5000` उघडेल!

### पद्धत २ (कमांड प्रॉम्प्ट / टर्मिनलद्वारे):
```bash
python app.py
```
त्यानंतर ब्राऊझरमध्ये जा आणि **`http://127.0.0.1:5000`** उघडा.
